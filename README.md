# Dosthai AI

Dosthai is a general-purpose AI assistant platform designed to grow toward a ChatGPT-style experience.

## Vision
- Conversational AI
- Streaming responses
- File and document understanding
- Web research
- Tool calling
- Memory
- RAG knowledge bases
- Agents and automation
- Coding and MuleSoft/DataWeave assistance
- Secure user workspaces

## Development

The initial application is intentionally small and modular. AI providers, tools, memory, RAG, and agents can be added without replacing the chat UI.

## Environment

Create `.env.local` from `.env.example` and configure an AI provider before enabling live model responses.
